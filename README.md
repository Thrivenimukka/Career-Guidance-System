# Career Guidance System

## Project Description

Career Guidance System is a web-based application developed using Python and Streamlit. It helps students identify suitable career paths based on their skills and interests.

## Objective

The main objective of this project is to provide personalized career recommendations to students and help them understand the skills required for different career paths.

## Technologies Used

- Python 3.11.9
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- NLTK
- spaCy
- Transformers
- PyTorch
- Sentence Transformers
- Google Gemini AI
- LangChain

## Features

- Student information input
- Skill-based career recommendations
- Interest-based career recommendations
- Career match score
- Career roadmap
- AI-based career guidance
- Skill gap analysis

## Career Options

The system can recommend careers such as:

- Data Scientist
- Data Analyst
- Software Developer
- AI Engineer
- Web Developer
